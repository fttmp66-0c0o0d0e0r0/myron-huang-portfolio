1. How I worked

I built this website using Google Antigravity as a coding assistant. I started by feeding it my exported LinkedIn PDF and past resume files. I told it to keep only my work experience, skills, and current research, while leaving out personal hobbies. Once the source files were ready, I asked Antigravity to create a portfolio page and open localhost:8038 so I could test the layout in Chrome. Most of my time went into small design tweaks after the first draft rather than writing the initial layout. Once everything looked good on my local machine, I prepared the code for GitHub Pages.

2. What I changed by hand

The first draft came out with dark backgrounds and neon colors that looked like a gaming website. Since I now study medical imaging, I wanted a softer look, so I asked for a clean baby-blue and white theme instead.

Whenever I wanted to adjust a section, I took a screenshot with the Windows Snipping Tool, drew boxes around what was wrong, and uploaded it with clear instructions.

Antigravity also made a funny mistake on my MayaMiner job: because the setting was an operating room, it drew my 3D figurine as a doctor in a lab coat with a stethoscope. I never operated on patients; I wrote hospital software that ran alongside doctors. After a few tries, the figure wore glasses, a collared shirt, and held a laptop.

The AI also dumped every detail from my resume onto the page, making it look cluttered. I cut out the walls of text and replaced them with short labels so the diorama images could speak for themselves. Around 70% in, I told Antigravity to stop adding unrequested features on its own.

3. What I learned (HTML5 Exam vs. AI Coding)

Ten years ago when I studied for my Microsoft HTML5 certification, I had to memorize tags, type out CSS rules, and fix broken box models by hand. Using Antigravity felt completely different: it wrote out working HTML and responsive styles in seconds.

Still, having that HTML5 foundation mattered a lot. If I did not know how DOM elements, image paths, and CSS classes worked, I would not have known why a section broke or how to tell the AI to fix it. Antigravity takes care of the repetitive typing, but knowing web basics is still necessary to guide the tool and keep the code clean.
