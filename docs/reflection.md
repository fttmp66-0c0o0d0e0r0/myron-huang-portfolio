### 1. How I worked

I built the site with Google Antigravity as a coding assistant. I started by uploading my exported LinkedIn PDF and my past CV files, then explained it which sections in files are the assignment needed: mainly my experience, skills and current research without too much about hobbies or private life.

After the files resource set up already, I gave first prompt for Antigravity is create a profolio website according to the attached files, then set up localhost:8038 channel for me to preview the template on browser. 

Most of my time went into small fixes after the first draft, not the draft itself. Once the site looked fine on my own computer, I deployed it to GitHub Pages.

### 2. What I changed by hand

The first version layout colors came out dark with neon colors that felt like a gaming, engineer site. Since I don't want the page looks too techy, I asked for a light baby-blue and white style to make it feel gentle and approachable.

To adjust the layout on website, I uploaded the screenshots by Snipping Tool from laptop OS default included which can circle the block I wanted to chang with prompt for giving directions.

Antigravity also drew the figurine in my MayaMiner picture as a doctor in a white coat with a stethoscope, I thought the reason was bulit in an operating room so that AI would create the normal thinking character in operating room is physian, actually I was a software engineer that coperative with medical personnel in that room. After several tries, the figure ended up of my cartoon character with glasses, a shirt and a laptop.

Whatever material I gave to the AI, it filled the page with all of it and made the homepage look mess, so I cut it down to a few labels and let the pictures show what each job was. When the work was about 70% done, I told Antigravity not to add features on its own or search the web for extra information unless I approved it with a new instruction.

### 3. What I learned

A generated page looks complete very quickly, which makes it easy to relax and stop checking. I still had to read the detail of website myself, confirm that the image paths would work on GitHub Pages, and reopen the page in the browser after every change.

The tool saved me a lot of time on layout and image generation also coding, but the facts about my own career and each coding permition from AI asking for changing still had to come from me and decided by me.
